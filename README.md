Macro for the roblox game "Bee Swarm Simulator" by Onett.
This macro is mainly for Linux as it's written in Python with the pyautogui library (which doesn't work for Windows,
unless you switch the library into pydirectinput)
This is my first big project.
Currently only works if your movespeed is 31 (like mine is). 
I will change it in the future to support all movespeed.
